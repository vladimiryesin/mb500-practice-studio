# MB-500 Practice Studio

Personal practice interface with 166 reviewed questions, including dropdown and drag-and-drop questions.

This static site runs directly on GitHub Pages. Publish from the `main` branch and the repository root. No build step is required.

Progress and imported question banks are stored in your browser. Use Back up progress and Restore to transfer progress between browsers or website addresses.

The bundled practice questions and explanations originate from Microsoft practice assessments. This interface is an independent study tool.
