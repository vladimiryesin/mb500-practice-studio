# MB-500 Learning Path

A short-session study app with 166 reviewed questions, including dropdown and drag-and-drop questions. It is installable from Android Chrome using **⋮ → Add to Home screen** and continues to work as a website.

Practice includes daily lessons, XP, streaks, exam mode, explanations, bookmarks, and review. Sign in with Google to sync progress between the website and your Android home-screen app. See [CLOUD-SETUP.md](CLOUD-SETUP.md) for install steps and what syncs.

Publish from the `main` branch and repository root. No site build service is required.

The bundled practice questions and explanations originate from Microsoft practice assessments. This interface is an independent study tool.
